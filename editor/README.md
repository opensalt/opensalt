# OpenSALT Editor (Vue)

This is a Vue 3 + Vite-based rewrite of the OpenSALT document tree and association editor UI.

## Getting Started

```
cd editor
npm install
npm run dev
```

Then open http://localhost:5173 in your browser.

## Status
- The tree view is being ported from the legacy jQuery code to Vue components.
- The UI is scaffolded with Bootstrap 5 and Bootstrap Icons.
- More features will be ported automatically.
